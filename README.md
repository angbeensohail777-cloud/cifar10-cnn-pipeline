# CIFAR-10 CNN Pipeline

An end-to-end reproducible Computer Vision pipeline for CIFAR-10 image
classification using PyTorch, Git, DVC, and DagsHub.

## Main Objective

Build a CNN that classifies CIFAR-10 images into 10 object classes
with a target test accuracy of at least 75%.

## Required Tools

- Python
- PyTorch
- Torchvision
- Git
- DVC
- DagsHub
